# Phase 8 开发记录：Progress 与身体记录

## 实现内容

- 新增身体快速记录页：体重必填、腰围可选，保存后写入 `BodyRepository` 并立即刷新 Dashboard。
- 新增数据趋势页，提供「体重 / 训练 / 营养」三个 Tab。
- 体重 Tab 展示当前 7 日平均、周期变化、趋势状态（数据不足 / 进度正常 / 下降偏慢 / 下降偏快）及每日代表值。
- 训练 Tab 展示本周完成次数和近期训练记录；营养 Tab 展示当日热量与蛋白质摘要。
- 底部「数据」导航改为进入 Progress；Dashboard 的体重卡片可直接进入身体记录。

## 验收记录

- `git diff --check`：通过。
- HAP 构建：通过，日志包含 `TYPE CHECK SUCCESSFUL` 与 `BUILD SUCCESSFUL`。
- 真机验收：通过。Dashboard 体重卡片进入「记录身体」，录入 `82.0 kg` 后返回 Dashboard 显示 `82.0 kg`，晨重待办变为完成，进度为 `3 / 5`。
