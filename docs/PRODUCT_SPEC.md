# 动谱产品功能规格

| 项目 | 内容 |
| --- | --- |
| 文档版本 | 0.3 |
| 状态 | 讨论稿 |
| 更新日期 | 2026-08-27 |
| 目标平台 | HarmonyOS NEXT 手机 |
| 核心人群 | 第一次开始健身房力量训练的成年人 |

## 1. 产品定位

动谱不是综合健身平台，也不是给资深训练者使用的专业记录器。它只解决健身小白进入健身房后的五个问题：

1. 今天练什么？
2. 这个动作怎么做？
3. 这一组该怎么记？
4. 下次从什么重量继续？
5. 如果我想自己练，怎样快速选部位和动作？

一句话承诺：**打开就知道今天练什么，照着做，顺手记下来。**

### 1.1 设计原则

- **一个明确答案**：优先告诉用户下一步，而不是先展示选项。
- **默认推荐、允许自定义**：小白可以直接跟练，也可以通过引导流程自己组计划。
- **一次一个动作**：训练中只聚焦当前动作。
- **普通人语言**：不用 RPE、1RM、训练容量等术语教育小白。
- **一组一次点击**：记录不能打断训练。
- **本地可靠**：断网、锁屏或应用被回收后仍能继续。
- **内容可信**：训练计划和动作要点发布前经过专业审核。

## 2. MVP 成功标准

一个完全没有力量训练经验的用户能够：

1. 用不超过 1 分钟完成首次设置。
2. 到健身房打开 APP，直接看到今天的训练。
3. 不自行挑选动作，也能完成一场 35—45 分钟训练。
4. 在每个动作前快速看懂器械、目标部位和 3 条动作要点。
5. 每完成一组，只操作一次即可记录并开始休息计时。
6. 器械被占用时，一次点击换成等价动作。
7. 下次训练时看到上次重量和次数。
8. 断网和异常退出后仍可继续训练。
9. 按“训练部位 → 动作”创建一次自定义训练，并可保存为计划重复使用。

## 3. 产品结构

底部只保留三个入口：

```text
训练    推荐训练、自定义训练、我的计划、训练中
动作    健身房动作查询与动作详情
记录    本周完成度与历史训练
```

设置通过“训练”页右上角进入，不单独占用底部入口。

## 4. 首次使用

### 4.1 首次设置

只询问必要信息：

1. 每周准备去几次健身房：2 次 / 3 次。
2. 训练日提醒：暂不开启 / 选择星期，提醒属于可选项。

随后说明：

- 首版计划面向无伤病限制的普通成年人。
- 有疼痛、伤病、孕期或医生限制的用户，应先咨询专业人士。
- 计划从轻重量开始，动作质量优先于重量。

不要求填写身高、体重、体脂、饮食目标、头像或注册账号。

### 4.2 默认计划

- 一个 4 周健身房新手计划。
- A/B 两套全身训练交替执行。
- 每周 2 次为默认节奏；选择 3 次时继续按 A/B 交替。
- 每次 4—6 个动作，目标时长 35—45 分钟。
- 优先选择容易理解和调整的固定器械动作，再逐步引入自由重量。
- 具体动作、组次和替换关系必须经过有资质教练审核后才能发布。

推荐计划本身不可编辑，避免用户误改内容；用户可以另行创建、编辑和保存自己的计划。训练过程中仍可跳过或替换当次动作。

## 5. 页面功能

### 5.1 “训练”首页

首页只回答“现在该做什么”。

#### 没有进行中训练

- 本周进度，例如“已完成 1 / 2 次”。
- 今天的训练：A 或 B、预计时长、动作数量。
- 唯一主按钮：“开始今天训练”。
- 次要按钮：“自定义训练”。
- “我的计划”区域：显示用户保存的自定义计划；没有计划时不展示空卡片列表。
- 非训练日显示“下次训练”和“仍然开始训练”。
- 右上角设置入口。

#### 有进行中训练

- 进行中训练卡片：已完成动作数、已用时间。
- 唯一主按钮：“继续训练”。
- 放弃训练放入次要菜单，并需要确认。

首页不展示资讯、课程推荐、热量、排行榜、商城或社区动态。

### 5.2 自定义训练与计划

用户可以临时决定今天练什么，也可以把组合保存为以后重复使用的计划。

#### 创建流程

```text
选择训练部位 → 选择动作 → 确认顺序和组次 → 开始训练 / 保存为计划
```

#### 第一步：选择训练部位

- 展示胸、背、肩、手臂、腿、核心等普通中文分类。
- 支持多选，默认建议选择 1—2 个部位，但不强制限制数量。
- 每个部位显示可选动作数量，不展示解剖学术语。

#### 第二步：选择动作

- 只显示所选部位下、适合健身房且内容已审核的动作。
- 默认把器械动作和推荐计划中出现过的动作排在前面。
- 支持中文搜索。
- 动作卡片显示示范缩略图、名称、器械和主要训练部位。
- 点击动作可看详情；勾选动作加入本次计划。
- 至少选择 1 个动作后才能继续。

#### 第三步：确认计划

- 调整动作顺序。
- 删除动作。
- 每个动作默认 3 组、8—12 次、休息 90 秒。
- 用户可以修改组数、次数范围和休息时间。
- 显示预计训练时长和动作数量。

#### 开始与保存

- “开始训练”直接创建本次训练，不要求先命名。
- “保存为计划”要求输入计划名称，随后可以立即开始。
- 临时训练完成后，完成页再次提供一次“保存为计划”的机会。
- 保存的计划可重命名、编辑、复制和删除；删除需要确认，不影响历史训练。
- MVP 不提供公开模板市场、计划分享或自动生成计划。

#### 简化规则

- 自定义入口不影响推荐训练的主按钮优先级。
- 不直接展示全部 1,324 个动作；必须先经过健身房适用性和内容审核筛选。
- 用户选择了多个部位时，动作列表按部位分组，避免混成一条长列表。
- 用户退出创建流程时保存本地草稿，再次进入可继续或放弃。

### 5.3 训练预览

点击开始后先看到极简清单：

- 今日动作顺序。
- 每个动作的计划组数和次数范围。
- 预计用时。
- 主按钮“开始第一个动作”。

用户可以查看动作详情，但不需要逐项确认或填写计划数据。

推荐训练、自定义临时训练和已保存计划进入同一套训练预览与训练中流程。

### 5.4 训练中

一次只显示当前动作：

- 动作名称和器械名称。
- 简短示范动画或图片。
- 当前第几组，共几组。
- 目标次数范围。
- 上次重量和次数；首次训练显示“从轻重量开始”。
- 重量和实际次数输入。
- 主按钮“完成本组”。
- 次要入口：“看动作要点”“器械被占用”“跳过动作”。

#### 记录规则

- 上次数据自动预填，用户通常只需确认或小幅修改。
- 重量支持一位小数，次数为非负整数。
- 每完成一组立即保存并自动进入休息倒计时。
- 完成最后一组后自动进入下一个动作。
- 用户可返回查看今天的动作清单，但不会离开训练状态。

#### 休息计时

- 默认 90 秒，可在计划内容中为不同动作设定。
- 显示“下一个动作/下一组是什么”。
- 支持跳过、暂停和加减 30 秒。
- 结束时优先使用振动和简短声音提示。

#### 器械被占用

- 展示最多 2 个经过审核的等价替换动作。
- 优先选择同一目标肌群、当前健身房常见器械或徒手动作。
- 替换只影响本次训练。
- 没有可靠替换时允许“稍后再做”，把动作移到本次训练末尾。

### 5.5 动作要点

动作说明固定为四块：

1. **练哪里**：主要目标肌肉，用普通中文表达。
2. **怎么做**：最多 3 个步骤。
3. **注意什么**：最多 3 个常见错误或安全要点。
4. **器械怎么调**：仅在有可靠内容时展示。

长篇解剖、辅助肌肉列表和多语言原始数据不在训练中展示。完整数据可以保留在底层。

### 5.6 “动作”页

动作库是辅助工具，不是首屏。

- 默认优先显示当前 4 周推荐计划涉及的动作。
- 支持按中文名称搜索全部动作。
- 支持按训练部位筛选，且只展示适合健身房、内容已审核的动作。
- 动作详情展示示范、简明要点和“在哪次训练中出现”。
- 动作详情可以“加入自定义训练”；如果尚未创建自定义草稿，则创建草稿并加入该动作。
- MVP 不提供收藏或复杂器械组合筛选。

### 5.7 训练完成

只展示对小白有意义的信息：

- “今天完成了”。
- 本次时长、完成动作数和完成组数。
- 本周完成度。
- 与上次相比有进步的动作，例如重量或次数增加。
- 主按钮“完成并返回”。
- 临时自定义训练额外显示次要操作“保存为计划”。

不展示 1RM、复杂容量图、卡路里估算或全站排名。

### 5.8 “记录”页

- 本周计划完成度。
- 按时间倒序的训练记录。
- 单次详情：动作、每组重量和次数。
- 动作历史只展示最近几次重量/次数，不做复杂趋势图。

历史数据不可因动作库或计划升级而丢失。MVP 不支持编辑已完成训练。

### 5.9 设置

- 每周训练次数：2 / 3。
- 默认训练日与可选提醒。
- 重量单位：公斤 / 磅。
- 媒体缓存清理。
- 数据来源和媒体版权。
- 隐私说明和训练免责声明。

## 6. 明确删除或后移的功能

以下内容仍退出 MVP：

- 收藏动作。
- 器械、目标肌肉等多维复杂组合筛选。
- 公开训练模板市场、计划分享和自动生成计划。
- 训练容量、个人纪录、月历和复杂统计。
- 多语言、数据导入导出和云同步。
- 社交、AI、饮食、商城、穿戴设备和健康数据。

## 7. 核心业务规则

- 同一时间最多存在一场进行中训练。
- 同一时间最多存在一个未完成的自定义训练草稿。
- 推荐计划、自定义计划和临时训练共用训练记录流程。
- 每次完成组、替换动作或跳过动作后立即保存。
- 异常退出后回到“继续训练”，保留开始时间和所有组数据。
- 历史记录保存动作名称快照，动作库更新不影响旧记录。
- 首次训练不替用户计算具体重量，只引导从可规范完成的轻重量开始。
- 替换关系由内容数据预先审核，不在客户端随机推荐。
- 动作媒体失败时，文字要点和训练记录仍然可用。
- 媒体授权不明确的内容不得进入发布包。

## 8. MVP 验收场景

1. 新用户选择每周 2 次，在 1 分钟内进入训练首页。
2. 用户不搜索动作、不创建计划，直接开始训练 A。
3. 用户看示范后录入第一组，点击一次进入休息计时。
4. 用户锁屏再解锁，倒计时和训练数据仍可恢复。
5. 器械被占用，用户替换动作后继续训练。
6. 应用被系统关闭，重新打开后继续同一训练。
7. 完成后记录页出现本次训练，下次自动显示上次数据。
8. 全程断网时，除未缓存动画外不影响完成训练。
9. 用户选择胸部和肩部、添加动作、修改顺序后开始一场自定义训练。
10. 用户保存自定义计划，重启 APP 后仍能从“我的计划”再次开始。
11. 删除自定义计划后，过去使用该计划完成的历史仍可阅读。

## 9. 待讨论决策

1. 推荐训练每次采用 4、5 还是 6 个动作；需要结合真实健身房测试控制在 35—45 分钟。
2. 首版计划是否只支持每周 2 次；当前保留 2 / 3 次选择，但两者共用 A/B 计划。
3. 自定义计划是否需要设置训练日；当前只保存动作组合，不强制排日历。
4. 是否加入训练日提醒；它不是核心功能，可以在真机权限验证后决定。
5. 如何获得计划、动作要点和替换关系的专业审核。
