# Phase 10 开发记录：P1 渐进与周期复盘基础

## 实现内容

- 训练历史加载增加双进阶规则：上一场同一动作的所有目标组均达到 `repMax` 且重量大于 0 时，下一次建议重量增加 2.5 kg；否则保持上一重量。
- 建议基于 `actual_exercise_id` 查询，动作替换仍能读取正确历史；当前场次已有记录时保持当前场次最近重量，不被旧记录覆盖；自重动作保持 0。
- 新增腰围趋势聚合，支持最近周期值、上一周期值及变化；无记录时显示可恢复的“每 1—2 周记录一次”空状态。
- 设置页提供今日步数手动录入，写入 `daily_activity`，作为健康数据权限接入前的稳定 fallback。
- Progress 体重页展示腰围摘要，训练页继续展示本周完成次数，作为周期复盘的基础指标。
- Dashboard 的训练 Checklist 仅在当天完成必做训练后勾选；活动卡可直接进入手动步数编辑。
- Progress 体重页展示最近 30 天代表值，营养页汇总本周平均热量和蛋白质达标天数。
- 设置页支持每周 2 / 3 / 4 / 5 次训练频率。
- 新增「本周复盘」页，从体重、腰围、训练、蛋白质、平均步数和力量亮点六个维度展示已记录数据，并明确标注数据不足状态。
